🚗  Concesionaria de Vehículos

Proyecto final desarrollado para Programación II
El sistema gestiona vehículos, clientes, empleados, proveedores, facturas y persistencia de datos en JSON

-——————————————————————

📊 Funcionalidades del sistema

- Gestión de vehículos (Autos, Camionetas, Camiones, Motos) 🚗🛵🚛
- Gestión de proveedores 🚚
- Gestión de clientes y empleados 👨🏼‍💼
- Sistema de usuarios (Admin / Usuario) 👨‍💻
- Facturación 🧾
- Serialización y deserialización JSON 📦
- Menú interactivo 🖥️
- Cálculo de dimensiones y carga según tipo de vehículo ➕✖️🟰➗➖
- Validaciones de datos ✅
